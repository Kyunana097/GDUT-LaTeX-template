% ==================== 中文摘要 ====================
\begin{zhabstract}
猪脚饭作为华南地区广受欢迎的传统美食，长期依赖人工制作，存在口味不稳定、出餐效率低等痛点。本文提出并设计了一套基于STM32F407嵌入式的智能猪脚饭机控制系统。硬件方面采用PT100铂电阻配合MAX31865实现$\pm 0.5$\textdegree C卤制温控，42步进电机驱动螺旋输送机构实现米饭定量配送；软件方面采用增量式PID算法控制卤制温度，并以微信小程序实现远程点单与支付。经20次实际烹饪盲测，出餐时间从传统平均8分10秒缩短至3分30秒，口味一致性评分标准差从0.74降至0.18，验证了设计方案的工程有效性。
\end{zhabstract}

% ==================== 英文摘要 ====================
\begin{enabstract}
Pig trotter rice, a beloved traditional fast food in southern China, suffers from inconsistent quality and slow service due to its reliance on manual preparation. This paper presents an STM32F407-based embedded control system for an automated pig trotter rice machine. The hardware features PT100 temperature sensing with MAX31865 ADC for $\pm 0.5$\textdegree C braising control and a 42-stepper-motor-driven screw mechanism for rice dispensing. The software employs incremental PID for temperature regulation and a WeChat mini-program for remote ordering. In 20 blind taste tests, average service time decreased from 8min10s to 3min30s, and taste consistency (SD of blind scores) improved from 0.74 to 0.18, validating the design.
\end{enabstract}

% ---- 第 1 章 ----
\chapter{绪论}

\section{研究背景与意义}
猪脚饭，又称隆江猪脚饭，源自广东揭阳隆江镇，以卤制猪蹄搭配米饭、酸菜为特色，是华南地区最具代表性的快餐之一。据统计，广东省内各类猪脚饭店铺超过8万家，年消费规模超过200亿元\upcite{ref1}。然而行业现状不容乐观：

\begin{enumerate}[label=（\arabic*）]
    \item 制作高度依赖厨师经验，卤制火候和调料比例难以标准化。
    \item 高峰期（11:30--13:00）排队等待时间普遍超过15分钟。
    \item 一线城市猪脚饭店主厨月薪在8000--12000元区间，人工成本挤压利润空间。
\end{enumerate}

嵌入式技术和物联网的快速发展为传统餐饮标准化、自动化提供了技术可能\upcite{ref2}。目前市场上已有智能炒菜机器人、自动面条机等产品，但尚无针对猪脚饭这一细分品类的自动化方案。因此，研发一款嵌入式驱动的智能猪脚饭机具有显著的产业应用前景。

\section{国内外研究现状}
餐饮自动化可追溯至20世纪80年代日本开发的自动寿司机。美国Momentum Machines公司研制的汉堡机器人可实现每小时400个汉堡的产能\upcite{ref3}。国内碧桂园千玺机器人集团研发了多款中餐烹饪机器人\upcite{ref4}。但现有研究多集中于通用型炒菜机器人或西式快餐自动化，对中式卤制类菜肴的自动控制研究尚属空白。

猪脚饭制作包含三个关键工序：卤制（猪蹄含八角、桂皮、酱油，小火慢炖2--3小时）、米饭蒸煮（米水比1:1.2，蒸25分钟）和配菜组装。其中卤制是核心，需将温度控制在85--95\textdegree C之间——过高导致肉质松散，过低则不入味。此温度区间的精确控制为嵌入式温控系统提供了明确的工程目标。

\section{本文结构}
第二章介绍系统总体架构，第三章详述硬件设计，第四章阐述PID控制算法，第五章展示测试结果。全文共5章。

% ---- 第 2 章 ----
\chapter{系统总体设计}

\section{需求分析}
经对5家猪脚饭店实地调研，归纳核心需求：

\begin{enumerate}[label=（\arabic*）]
    \item 卤制温控精度：温度波动不超过$\pm 2$\textdegree C。
    \item 出餐速度：单份$\leq$4分钟。
    \item 口味一致性：连续制作20份，5人盲测评分变异系数$\leq 5\%$。
    \item 远程控制：支持微信小程序下单、支付、查看进度。
    \item 食品安全：卤汁温度传感器需达食品级防护（IP67）。
\end{enumerate}

\section{系统架构}
系统采用"云-边-端"三级架构：

\begin{description}
    \item[端侧] STM32F407为主控，搭载PID温控模块、步进电机驱动、称重传感器（HX711），负责卤制、配饭、装盘的实时控制。
    \item[边侧] 树莓派4B作本地网关，运行Node.js服务，断网时可离线管理200条以内订单。
    \item[云侧] 腾讯云轻量服务器部署订单管理系统，小程序通过HTTPS与云服务器通信，云与边之间通过MQTT下发指令。
\end{description}

% ---- 第 3 章 ----
\chapter{硬件设计与实现}

\section{主控与温控模块}
选用STM32F407VET6作主控，主频168MHz，具备DSP浮点运算能力，适合PID实时计算。温度传感器选用PT100铂电阻，配合MAX31865模数转换器实现0.03125\textdegree C分辨率。卤制锅体采用304不锈钢，底部嵌入1500W电热管，STM32输出PWM驱动固态继电器调节加热功率。

\section{配饭与装配模块}
米饭配送采用螺旋输送机构，由42步进电机驱动。称重传感器HX711实时监测出饭量，达目标值（200$\pm$5 g）时停止。酸菜和卤蛋添加由两个舵机控制的挡板机构完成。

% ---- 第 4 章 ----
\chapter{PID 控制算法与软件设计}

\section{增量式 PID 温控}
卤制温度控制采用增量式PID，控制周期1秒：

\begin{equation}
    \Delta u(k) = K_p [e(k)-e(k-1)] + K_i e(k) + K_d [e(k)-2e(k-1)+e(k-2)]
    \label{eq:pid}
\end{equation}

经Ziegler-Nichols法整定参数：$K_p=18.5$，$K_i=0.8$，$K_d=3.2$。设定温度90\textdegree C，超调量$<1.5$\textdegree C，稳态误差$\pm 0.5$\textdegree C，达到设计指标。

\section{微信小程序}
小程序采用微信云开发框架，WXML+WXSS前端，云函数处理订单生成。用户扫码→选规格（大份/小份、加卤蛋/不加）→支付→订单推送至树莓派网关。

\section{不足与改进方向}
当前仅支持单卤锅，高峰期产能受限（理论最大15份/小时）；卤料配比仍依赖人工预调包；未针对不同产地猪蹄的肉质差异做自适应参数补偿。

% ---- 第 6 章 ----
\chapter{结论}
本文设计了基于STM32的智能猪脚饭机控制系统。经PID温控、步进电机配饭和微信小程序远程下单的集成，出餐时间缩短57\%，口味一致性提升显著。本研究为中式卤制类快餐的自动化转型提供了可借鉴的工程方案。

当一碗猪脚饭背后站着STM32、PID算法和MQTT协议时，它就不再仅仅是碳水与胶原蛋白的组合，而是第四次工业革命深入日常生活的一个微小而确切的注脚。
